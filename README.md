# Kurdish (Behdini) Language Dataset

This repository contains datasets of the Kurdish (Behdini) dialect, extracted from a dictionary app, including:

- **Verbs** with tense and person forms
- **Expressions** in Behdini (Latin & Arabic) and English
- **Proverbs** in Behdini (Latin & Arabic) and English
- **Bilingual Dictionary** covering English, Behdini (Latin & Arabic), and transliterations

### Goals

- Make Kurdish (Behdini) resources available for AI, NLP, and linguistic research.
- Support education and accessibility of Kurdish to the global community.

### Structure

```
/data
├── Dictionary_English-BehdiniLatin-BehdiniArabic-Arabic-Transliteration.csv
├── Expressions_BehdiniArabic-BehdiniLatin-English.csv
├── Proverbs_BehdiniArabic-BehdiniLatini-English.csv
├── Verbs_Verb-Tense-Person-English-BehdiniLatin-BehdiniArabic.csv
```

Each file is UTF-8 encoded CSV, designed to be both human-readable and machine-usable.
